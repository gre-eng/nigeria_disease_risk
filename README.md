# Nigeria Disease Risk Intelligence Platform

[![DOI](https://zenodo.org/badge/1281904577.svg)](https://doi.org/10.5281/zenodo.24125379)

Cholera hotspot analysis, Lassa fever forecasting, and resource allocation for Nigeria, using NCDC, HDX and World Bank data.

Live app: https://nigeria-disease-risk.onrender.com

## Run locally

    pip install -r requirements.txt
    streamlit run app.py
